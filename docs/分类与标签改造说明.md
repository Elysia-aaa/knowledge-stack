# 分类与标签改造

本次采用确认后的规则：固定 17 个学科大类、多选、发布至少一项、草稿可空；标签逐个添加/移除，最多 10 个，每个最多 20 个字符，英文大小写重复不再添加。

## 使用方式

1. 在“写文章”或“编辑文章”中勾选学科，可同时选择“计算机”“医学”等多个分类。每个分类都能在文章列表中独立筛选这篇文章。
2. 输入 `#示例标签A` 或 `示例标签A`，点击“添加标签”或按回车，生成 `#示例标签A` 标签块。`#` 是展示前缀，不存入标签名。
3. 点击标签旁的 × 移除。添加/移除后发布或保存草稿，修改才写入数据库；未添加的输入会在提交时提醒处理。
4. 允许 `C#`、`C++`、`ASP.NET`。不允许标签内部有空格、逗号、分号、换行；`ASP.NET` 和 `asp.net` 视为重复。
5. 重新编辑时恢复已勾选分类和已有标签块。首页、文章列表、详情、个人主页、收藏/草稿等展示同步采用新格式；点击分类或标签可筛选文章。

## 数据与代码

- `database/002_taxonomy.sql`：增量迁移；Categories 为目录，PostCategories 为文章多对多关联，有外键、联合主键和分类索引。彻底删除文章时级联清理分类关联，软删除保留关联。
- `DAL/TaxonomyDAL.cs`：自定义数据库访问与规则类；数据库目录白名单阻止手工伪造分类，服务端校验标签格式和数量。
- `DAL/PostDAL.cs`：事务保存文章、分类、图片关联；从关联表读出分类；分类筛选使用 EXISTS，不会因多选重复返回文章。
- `PostEdit.aspx` / `.cs`、`Scripts/post-taxonomy.js`：可访问的复选框组、标签块、按钮/回车交互、即时提示与服务端错误回显。
- `Utils/HtmlRenderer.cs`、`PostDetail.aspx.cs`、`Scripts/community.js`：每个分类/标签独立生成筛选链接，用户输入经编码展示。
