# 个性化主题与创作数据

确认日期：2026-10-26。仅本地开发，不包含云端发布。

## 已确认范围

- 六套预设：经典白、夜间黑、海洋蓝、森林绿、樱花粉、暖橙。仅改变本人全站浏览效果。
- 账号数据库保存当前选择和一套自定义配色。实时预览、保存、取消、恢复默认。切换预设保留自定义。访客使用本机主题，登录使用账号设置，退出不展示其他账号的自定义设置。
- 可调整主色、链接、按钮、页面、卡片、导航、正文、次级文字、边框、代码区。低对比提醒，提供一键改善；不强行覆盖用户选色。背景图片不在本轮。
- 作者私有后台：总览、阅读/互动/粉丝趋势、文章数据表、单篇详情、最多3篇对比、CSV导出。布局借鉴创作者数据后台，配色跟随本站主题。其他访客保持原公开资料。
- 时间：近7/30/90天、自定义、累计。非累计范围与上一等长周期对比。日期按北京时间，长范围按月聚合。
- 热度仍为点赞×3＋收藏×4＋有效评论×2。后台显示当前热度、逐篇排行和已采集的每日热度快照；公共热榜计算规则保留。
- 保留旧文章和数据。浏览记录可恢复日期趋势；新增/取消、粉丝变化、阅读时长和完读仅从启用后完整采集。缺失记录标为未采集，不以0冒充历史。
- 创作数据后台、图表及导出仅使用真实数据库数据；模拟展示入口与数据生成逻辑已移除。

## 统计口径

- 阅读量：同读者同文章每天一次，排除作者本人；登录按账号、游客按浏览器随机标识。独立读者在选择范围内去重，游客跨设备无法精确合并。
- 时长：前台且60秒内有阅读操作时累计，切后台暂停；以页面行为估算，非真实注意力证明。
- 完读：正文末尾进入可视区域且累计有效阅读至少10秒，同读者同文章每天一次。完读率以启用后采集的阅读为分母。
- 互动率：在所选时段读过且对同篇文章有过赞、藏、评论或转发的去重读者 / 独立读者。最高100%，同一读者多项互动不重复计分。
- 新增与取消分开记录，净增允许负数；当前有效关系与区间发生量分别命名。粉丝展示当前总量、新增、取关、净增。
- 草稿不采集阅读；曾发布后撤回、隐藏或移入回收站的文章保留历史并标状态。彻底删除清除单篇明细。文章筛选不影响粉丝指标的作者级含义。

## 实现与验收

新增幂等迁移，不清空原库；测试使用独立数据库。主题接口只写当前账号，统计接口只返回本人文章。图表库本地打包，断网仍可演示。

验收覆盖：六主题、账号隔离和持久化、非法颜色/防伪校验、读取他人统计失败、重复阅读去重、时长/完读、赞藏与关注增减、区间与对比、删除/隐藏状态、真实数据图表与导出、手机图表、原有功能回归。
